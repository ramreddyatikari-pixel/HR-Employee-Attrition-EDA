# HR Employee Attrition - Exploratory Data Analysis (EDA)

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the IBM HR Employee Attrition dataset.

The objective is to understand the factors that influence employee attrition through data visualization and statistical analysis.

---

## Dataset

IBM HR Analytics Employee Attrition Dataset

Kaggle:
https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## EDA Performed

- Dataset Overview
- Missing Value Check
- Duplicate Check
- Summary Statistics
- Attrition Distribution
- Age Distribution
- Overtime vs Attrition
- Monthly Income vs Attrition
- Job Satisfaction vs Attrition
- Department vs Attrition
- Correlation Heatmap

---

## Key Findings

- Most employees stayed with the company.
- Employees working overtime showed higher attrition.
- Employees with lower monthly income had higher attrition.
- Job satisfaction appears related to employee retention.
- Attrition varies across departments.
